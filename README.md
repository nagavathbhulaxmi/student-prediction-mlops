# Student Prediction Website – MLOps Project

## Project Overview
This project predicts student marks based on study hours, attendance, and previous marks using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Git and GitHub

## Project Files
- `train.py` – Trains the Machine Learning model.
- `app.py` – Runs the Flask web application.
- `requirements.txt` – Lists the required Python libraries.
- `.gitignore` – Excludes unnecessary files from Git.

## How to Run Locally

1. Clone the repository:
   `git clone https://github.com/nagavathbhulaxmi/student-prediction-mlops.git`

2. Open the project folder:
   `cd student-prediction-mlops`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Train the model:
   `python train.py`

5. Start the website:
   `python app.py`

6. Open your browser and visit:
   `http://127.0.0.1:5000`

## Note
This is a learning project using sample data. Predictions are for demonstration purposes and are not validated for real-world student assessment.
